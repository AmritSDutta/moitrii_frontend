# UI Screens

Moitrii has six core user-facing screens covering the full lifestyle agent lifecycle.

## 1. Public Landing & Explore (`/`)

**Access:** Public (no auth required)

- Editorial header with category navigation strip (Health, Food, Beauty, Wellness, Kids, Home, Travel, Anime, Gen-Z)
- Hero section with warm lifestyle banner, search bar, and popular search pills
- "What's Hot" — featured articles sorted by reuse count
- "Popular Categories" — interactive topic grid cards
- "Latest Stories" — browsable article grid with reuse badges
- "Trending Videos" — curated YouTube video cards with modal player
- "About Moitrii" mission footer with multi-language greetings

## 2. Onboarding & Interest Selection (`/onboarding`)

**Access:** Auth required (AuthGuard)

- Two-column topic grid split into:
  - **Core Lifestyle & Mindful Living** (lifestyle + wellness categories)
  - **Parenting & Youth Culture** (parenting category — Gen-Z, Anime, Comics)
- Interactive toggle cards with icon, description, and popular search tags
- Floating summary bar showing selected topic count
- "Save & Go to Dashboard" action persists interests to Convex and navigates to `/dashboard`

## 3. Agent Dashboard (`/dashboard`)

**Access:** Auth required (AuthGuard)

- **Greeting Hero:** Personalized "Good Morning, {name}" with agent logo
- **Agent Status Box:** Live status badge (`SLEEPING` / `ACTIVE` / `WORKING` / `WAITING` / `ERROR`), status message, subscription tier, and demo "Simulate Wake Cycle" button
- **Wake-Up Schedule Card:** Next scheduled wake time, frequency, last active timestamp
- **Quick Request Composer:** Natural language prompt input with category dropdown → `createRequest` mutation
- **Active Interests Strip:** Followed topics as pills with edit link to `/onboarding`
- **Agent Work Feed:**
  - **Ready to Read** — completed deliverables with "Read Guide" link to `/content/[id]`
  - **Queued Tasks** — pending/processing requests with wake window indicator

## 4. Request Center & History (`/requests`)

**Access:** Auth required (AuthGuard)

- **Request Composer:** Textarea with topic selector → `createRequest` mutation
- **Filter Pills:** All / PENDING / COMPLETED
- **Request History List:** For each request shows:
  - Status badge (`PENDING` / `PROCESSING` / `COMPLETED` / `FAILED`)
  - Category tag
  - Prompt text
  - Delivered guide title (if completed)
  - Reuse status: "Shared Knowledge Reuse" vs "Freshly Researched & Synthesized"
  - Submission timestamp
  - Link to content reader (if completed)

## 5. Content Reader (`/content/[id]`)

**Access:** Public

- Back button navigating to previous page
- Header: category badge, reuse count badge, title, subtitle
- Metadata row: author, read time, publish date, share button
- Editorial cover photo (16:9 aspect ratio)
- **Agent Key Takeaways** — bulleted list with check icons
- **Video Companion** — embedded YouTube player (if `youtubeId` present)
- **Article Body** — markdown-rendered content with `###` and `####` subsections
- **Verified Sources** — citation list with external links
- **Related Stories** — two related article cards from the shared ecosystem

## 6. Publisher Studio (`/publisher`)

**Access:** Auth required (AuthGuard)

- **Mode Toggle:** Compose / Live Preview
- **Article Meta Form:** Title, subtitle, category, author byline, read time
- **Cover Image:** URL input or file upload to Convex File Storage
- **YouTube:** Optional video ID and title fields
- **Key Takeaways Builder:** Add/edit/remove takeaway bullets (numbered)
- **Markdown Editor:** Textarea for article body with live preview
- **Publish Action:** Calls `publishContent` mutation → redirects to `/content/[slug]`
