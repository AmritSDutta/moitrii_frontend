# Moitrii — Personal AI Companion for Women

Moitrii is an affordable personal AI agent platform built for the modern Indian woman. Every user gets a dedicated, persistent personal AI agent that sleeps between cycles and wakes on a schedule determined by the subscription tier to research, generate, or reuse lifestyle content.

Indian women (and likely women globally) are least interested in chat-based or existing modes of AI interaction, yet they still need to unlock the benefits of AI. After discussions with a few friends, sisters, and my wife, I found that their fundamental needs remain the same: they lack time to bridge skill gaps, and day-to-day challenges persist. They need support with fashion, shopping, recipes, educational tips for their children, and coping with growing kids.

## Core Principle

All users receive **identical** agent capabilities. Subscription tiers determine only **execution frequency** (wake periodicity) — not feature access.

## Key Features

- **1 User ➔ 1 Distinct Personal Agent** — Dedicated personal AI companion (`Moitrii Companion`) with its own virtual inbox (`agent-...@agentmail.to`).
- **Sleeping Agent Model** — Agent sleeps and wakes periodically based on subscription tier (defaults to 11:00 PM IST with 9 PM–9 AM calm-tech window).
- **Modular Cloud AI Engine (`convex/ai/`)** — Realtime reuse engine, dynamic date prompts, Firecrawl web search tool, multilingual synthesis (English, Bengali, Hindi), Sarvam Bulbul v3 TTS audio narration with OpenAI fallback, 16:9 pictorial infographics, and YouTube video discovery.
- **Dual-Channel Messaging Separation** — Brevo for newsletter broadcasts & welcome emails; AgentMail for 1:1 personal agent research updates.
- **Strict PII Anonymization** — Human names and personal emails exist solely in `users` table; all agent state and content references use opaque IDs.
- **Dispute & Moderation Safety** — `users.isActive` safety switch instantly guards agent execution and request queues.
- **Shared Knowledge Ecosystem** — Agents reuse verified guides to avoid duplicate generation costs.
- **Convex Realtime Backend** — End-to-end TypeScript with type-safe queries, mutations, full-text search, and File Storage.
- **Google OAuth Authentication** — Built on `@convex-dev/auth/react`.
- **Editorial Lifestyle Aesthetic** — Warm, calm, magazine-like UI distinct from generic SaaS dashboards.

## Technology Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React 18, Vite 5, React Router v6, TypeScript |
| Styling | Tailwind CSS 3, custom editorial color palette |
| Backend | Convex Cloud (`brazen-rook-983` — Database, Queries, Mutations, File Storage, Crons) |
| AI Engine | Modular Convex AI Pipeline (`convex/ai/` — reuse, synthesis, TTS narration, research) |
| Email & Messaging | Brevo (platform/subscribers) & AgentMail (1:1 personal agent inboxes) |
| Auth | `@convex-dev/auth/react` with Google OAuth |
| Icons | Lucide React |

## Quick Start

```bash
npm install
npm run dev
```

This starts the Vite React dev server at `http://localhost:3000`. You also need `npx convex dev` to run the Convex backend locally (configured via `VITE_CONVEX_URL`).
