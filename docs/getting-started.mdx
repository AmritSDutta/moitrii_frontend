# Getting Started

## Prerequisites

- **Node.js 18+** (tested with Node 18/20)
- **npm** (or compatible package manager)
- **Convex CLI** — install via `npm install -g convex` or use `npx convex`
- **Google OAuth credentials** — required for local auth (see below)

## Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/AmritSDutta/moitrii_frontend
cd moitrii_frontend
npm install
```

## Environment Setup

Create a `.env.local` file in the project root with your Convex deployment URL:

```bash
NEXT_PUBLIC_CONVEX_URL=https://<your-deployment-name>.convex.cloud
```

For local development, run `npx convex dev` to link your local Convex backend.

## Development Commands

| Command | Description |
|---------|-------------|
| `npm run dev` | Start the Next.js frontend dev server at `http://localhost:3000` |
| `npx convex dev` | Start the local Convex backend with hot reload |
| `npm run build` | Create a production frontend build |
| `npm run lint` | Run the Next.js linter |
| `npm run start` | Start a production frontend server |

## Environment Variables & Credentials

Set these configuration variables in your Convex Dashboard for your deployment (`brazen-rook-983`):

### 1. Google OAuth
- `AUTH_GOOGLE_ID` — Google OAuth Client ID
- `AUTH_GOOGLE_SECRET` — Google OAuth Client Secret

### 2. Email & Messaging Channels
- `BREVO_API_KEY` — API key for Brevo transactional welcome emails and weekly broadcasts
- `BREVO_SENDER_EMAIL` — Verified sender email (e.g., `newsletter@moitrii.com`)
- `BREVO_SENDER_NAME` — Sender display name (`Moitrii Lifestyle`)
- `AGENTMAIL_API_KEY` — API key for AgentMail 1:1 agent dispatch
- `AGENTMAIL_DOMAIN` — Custom agent domain (defaults to `agentmail.to`)

### 3. AI & Synthesis Pipeline
- `OPENAI_API_KEY` — API key for LLM guide synthesis and TTS audio narration
- `AGENT_SERVICE_SECRET` — Shared secret for securing HTTP webhook callbacks (`POST /api/agent/complete`)
- `PYTHON_AGENT_ENDPOINT` — Optional fallback external agent webhook URL
